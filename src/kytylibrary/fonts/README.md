# Bundled fonts

Unmodified Google Fonts variable TTFs, downloaded 2026-09-05:

- Roboto: https://github.com/google/fonts/tree/main/ofl/roboto
  (`Roboto[wdth,wght].ttf`, stored as `Roboto.ttf`).
- Roboto Mono: https://github.com/google/fonts/tree/main/ofl/robotomono
  (`RobotoMono[wght].ttf`, stored as `RobotoMono.ttf`).

Each font's SIL Open Font License is kept alongside it and installed with the application.
The font data is embedded in the Qt resource collection and loaded with QFontDatabase.
Roboto is the application UI family; Roboto Mono is used for process output.
